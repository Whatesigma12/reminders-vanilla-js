# Напоминания js vanilla

Проект на чистом HTML, CSS и JavaScript.

## Запуск

Откройте `index.html` в браузере или используйте расширение Live Server в VS Code.

## Функции

- добавление напоминаний;
- пользовательская тема задачи;
- дата события;
- приоритет;
- подзадачи;
- отметка выполнения;
- поиск и фильтрация;
- сохранение в LocalStorage.
